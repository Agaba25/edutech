## ⚡ THE 3 CRITICAL STEPS

### ✅ STEP 1: Import New Database (MOST IMPORTANT!)

**Without this, your course finder won't work!**

1. Open: `http://localhost/phpmyadmin`
2. Delete old `edutech_db` database (Operations → Drop database)
3. Create NEW database: `edutech_db`
4. Import **File 1:** `database_enhanced.sql` → Click "Go"
5. Import **File 2:** `database_courses_enhanced.sql` → Click "Go" ⭐
6. ✅ Done!

**Verify:** You should see `courses` table with 8 courses.

---

### ✅ STEP 2: Clear Browser Cache

Your browser is showing OLD pages! Clear it:

1. Close ALL browser tabs
2. Press **Ctrl + Shift + Delete**
3. Select: **Cached images** and **Cookies**
4. Time: **All time**
5. Click **Clear data**
6. Close browser completely

---

### ✅ STEP 3: View Your Changes

1. Open NEW browser
2. Go to: `http://localhost/edutech/`
3. Press **Ctrl + F5** (hard refresh)
4. ✅ Should see: Full-screen image + "Edu_Career Guide Students Web"

### No courses found?
→ Check `database_courses_enhanced.sql` was imported

### Database error?
→ Stop MySQL in XAMPP, wait 3 seconds, start again
